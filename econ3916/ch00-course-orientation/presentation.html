How the Course Works

Theory seminar, then computational lab — every single session

The big idea: Concept Extension

Every machine learning algorithm in this course arrives as a computational scaling of something you already know. Ridge is OLS with a penalty. Random Forests are decision trees that vote. Double ML combines flexible prediction with the identification logic of IV. There are no discontinuities — only extensions.

This course sits in a gap the curriculum leaves open —

Your econometrics courses

taught you to think causally — does X cause Y? — but stopped at OLS on small, clean datasets.

Computer science courses

hand you powerful prediction tools but never ask whether the pattern reflects a mechanism or a coincidence.

We run the whole arc — measurement and EDA, inference and A/B testing, DAGs and SQL, then OLS → regularization → trees → time series → text → causal ML — and end with a deployed project you can hand an employer.

Prerequisite — but don’t stress: no prior programming is assumed. You need ECON 2350 (statistics); everything in Python we build from the first line. If you have never written code, you are exactly who the first six topics are written for.

What you’ll be able to do by December

 Write Python from scratch

Pull data from FRED, manipulate panels with pandas, run regressions with statsmodels, deploy Streamlit dashboards.

 Tell prediction from causation

Frame any empirical question as one or the other — and pick the method that actually fits it.

 Build a full pipeline

Query with SQL via DuckDB, model with scikit-learn, deploy a dashboard, push every lab to a GitHub portfolio.

 Use AI responsibly

Work with Northeastern’s Claude under P.R.I.M.E., progressing to directing multi-step agentic workflows.

 Practice on real data

Deflate wages with CPI, decompose GDP seasonality, score FedSpeak sentiment, estimate effects from observational data.

 Talk to stakeholders

One visual, one claim, one recommendation — and know when to say “that’s predictive importance, not a causal effect.”

Every one of these is a line you will be able to defend in a co-op interview — which is, honestly, half the point of the course.

The AI policy: foundations first, expansion second

Northeastern gives you enterprise Claude free at claude.northeastern.edu. You will use it constantly — on a schedule.

 Part A — AI code generation prohibited

Every lab runs its manual parts first. You type the loop, the merge, the regression call. This is where the muscle memory comes from.

 Part B — AI required

Then the boundary lifts and you extend the analysis with Claude, documenting each step with the P.R.I.M.E. framework: Prep, Request, Iterate, Mechanism check, Evaluate.

The boundary is explicit and non-negotiable: if you cannot explain a line of AI-generated code, you cannot submit it. This is not me being difficult. Students who can write code from scratch can audit, fix, and extend what a model gives them. Students who cannot are permanently dependent — and that shows up in a technical interview within about four minutes.

By the last third of the course you are not writing prompts — you are directing Claude Code through multi-step workflows and checking its work. That progression is deliberate.

How to do well (the honest version)

Plan for roughly 12 hours/week outside class. That is what a 4-credit course expects, and three 65-minute meetings are only a small part of it. The structure makes those hours predictable — not lighter.

  • Respect the muscle memory — in the first half, resist copy-paste. Typing the code manually is how you earn the right to audit AI output later.
  • Show up — the lab is the class, and the one attendance poll each session is 10% of your grade for being in the room.
  • Ask why before how — a high R² means nothing if the causal mechanism is wrong. That distinction is what makes you an economist rather than a model-fitter.
  • Build your portfolio early — push every lab, deploy every dashboard. By December the repo is the interview.
  • Document your AI usage — every P.R.I.M.E. entry is a professional habit you are rehearsing, not paperwork.
  • Ask for help — a stuck notebook is a five-minute fix in office hours and a lost weekend alone.
