Big idea

The 2316 shift from 1116 is calculus everywhere. Every “marginal” is now a derivative; every constrained-optimization problem is a Lagrangian. If you can write the Lagrangian and take the FOCs, the test mostly takes care of itself.

2.5Movement vs Shift
  • \(Q^d(P), Q^s(P)\) as functions
  • Inverse: \(p^d(Q), p^s(Q)\)
  • Linear: \(Q = a - bP\)
  • Slope = \(dQ/dP\)
  • Solve \(Q^d(P^*) = Q^s(P^*)\)
  • Find \(P^*, Q^*\)
  • Algebraic, not graphical
  • Single equation in \(P\)
  • \(CS = \int_0^{Q^*}\!(p^d(q) - p^*) dq\)
  • \(PS = \int_0^{Q^*}\!(p^* - p^s(q)) dq\)
  • Linear → triangles
  • Nonlinear → integrate
  • Total-differentiate eq. condition
  • \(\dfrac{dP^*}{d\alpha}, \dfrac{dQ^*}{d\alpha}\)
  • Sign + magnitude
  • Predicts shift outcomes
  • Movement: \(P\) changes → \(Q\) adjusts
  • Shift: parameter \(\alpha\) changes → curve moves
  • Math: \(\partial/\partial P\) vs \(\partial/\partial \alpha\)
  • Don’t confuse
Key takeaway: CS and PS are integrals: \(CS = \int_0^{Q^*}\!(p^d(q) - p^*)\, dq\). In the linear case the integral reduces to \(\tfrac{1}{2} Q^*(p^d(0) - p^*)\) — the familiar triangle.

Elasticity and Government Intervention
3.1Point Elasticity
3.2Cross & Income
3.3Tax Incidence
3.4DWL of a Tax
3.5Price Controls
  • \(\varepsilon = \dfrac{dQ}{dP} \cdot \dfrac{P}{Q}\)
  • Derivative form (NOT midpoint)
  • \(|\varepsilon| > 1\) elastic
  • \(Q = AP^{-\eta}\): \(\varepsilon = -\eta\)
  • Income: \(\varepsilon_I = \dfrac{dQ}{dI} \cdot \dfrac{I}{Q}\)
  • \(\varepsilon_I > 1\) luxury, \(<0\) inferior
  • Cross-price: \(>0\) substitutes
  • \(<0\) complements
  • Consumer share: \(\dfrac{\varepsilon_S}{\varepsilon_S - \varepsilon_D}\)
  • Legal payer \(\ne\) economic burden
  • More inelastic side pays more
  • Symmetric for subsidy
  • \(DWL \approx \tfrac{1}{2} t \Delta Q\) (triangle)
  • Scales with \(t^2\)
  • Bigger if either curve more elastic
  • Welfare loss from wedge
  • Ceiling below \(P^*\) → shortage + DWL
  • Floor above \(P^*\) → surplus + DWL
  • Non-binding = no effect
  • Subsidy = negative tax
Key takeaway: Point elasticity uses the derivative: \(\varepsilon = \dfrac{dQ}{dP} \cdot \dfrac{P}{Q}\). Tax incidence depends on the ratio of elasticities, not which side legally pays.

  • Completeness: rank any two
  • Transitivity: A > B > C ⇒ A > C
  • Monotonicity: more is better

  • Set of equally-preferred bundles
  • Convex → bowed-in IC

  • \(\text{MRS} = MU_1 / MU_2\)
  • Via implicit diff of \(U = \) const
  • Slope of IC (absolute value)
  • Diminishing along convex IC
  • \(U(x_1, x_2)\) encodes ranking
  • Ordinal not cardinal
  • Utility level itself is meaningless
  • Only the order of bundles matters
  • Cobb-Douglas: \(x_1^\alpha x_2^{1-\alpha}\)

Constrained Choice   — THE BIG ONE
5.1Budget Constraint
5.2Lagrangian Setup
5.3FOCs / Tangency
5.4Cobb-Douglas Demand
5.5Corner Solutions
  • \(p_1 x_1 + p_2 x_2 = I\)
  • Slope \(-p_1/p_2\)
  • Intercepts \(I/p_i\)
  • Price change → rotation
  • Income change → parallel
  • \(\mathcal{L} = U + \lambda(I - p_1 x_1 - p_2 x_2)\)
  • Convert constrained → unconstrained
  • \(\lambda\) is the multiplier
  • One \(\mathcal{L}\) per constraint
  • \(MU_i = \lambda p_i\) for each \(i\)
  • Tangency: \(\text{MRS} = p_1/p_2\)
  • Equimarginal: \(\dfrac{MU_i}{p_i} = \lambda\)
  • \(\lambda\) = MU of income
  • \(x_i^* = \alpha_i I / p_i\)
  • Spending share = exponent
  • No cross-price effect
  • Own-price elasticity = \(-1\)
  • Income elasticity = \(+1\)
  • Perfect subs: corner on higher \(MU/p\)
  • Perfect comp: \(ax_1 = bx_2\) + budget
  • Kinked budgets (SNAP, ACA)
  • Tangency may fail at corners
Key takeaway: Write \(\mathcal{L} = U(x_1, x_2) + \lambda(I - p_1 x_1 - p_2 x_2)\). FOCs give \(\dfrac{MU_1}{p_1} = \dfrac{MU_2}{p_2} = \lambda\). Tangency: \(\text{MRS} = p_1/p_2\). For Cobb-Douglas, just use \(x_i^* = \alpha_i I / p_i\).

Income, Substitution, and Demand
6.1Income & Engel
6.2Marshallian Demand
6.3Hicksian Demand
6.4Slutsky Equation
6.5Good Types & Market
  • Income elasticity: sign by type
  • Normal: \(\partial x/\partial I > 0\)
  • Inferior: \(\partial x/\partial I < 0\)
  • Engel curve: \(x\) vs \(I\)
  • \(x(p, I)\) from utility max
  • The Ch 5 solution, as a function
  • Holds nominal income fixed
  • Combines SE + IE
  • \(h(p, \bar u)\) from expenditure min
  • Holds utility fixed
  • “Compensated” demand
  • Always slopes down: \(\partial h/\partial p \leq 0\)
  • \(\dfrac{\partial x}{\partial p} = \dfrac{\partial h}{\partial p} - x \cdot \dfrac{\partial x}{\partial I}\)
  • SE always \(\leq 0\)
  • IE: sign of \(\partial x/\partial I\)
  • For normal good: IE reinforces SE
  • Normal: \(\partial x/\partial I > 0\)
  • Inferior: \(\partial x/\partial I < 0\)
  • Giffen: inferior + IE dominates SE
  • Market \(X(P) = \sum_i x_i\)
Key takeaway: \(\dfrac{\partial x}{\partial p} = \underbrace{\dfrac{\partial h}{\partial p}}_{\text{SE} \leq 0} - \underbrace{x \cdot \dfrac{\partial x}{\partial I}}_{\text{IE}}\). For a normal good, IE reinforces SE (both negative). For Giffen: inferior AND IE dominates.

Production Functions
7.1\(f(K, L)\) & MP
7.2Isoquants
7.3MRTS
7.4Returns to Scale
7.5Families + SR/LR
  • \(Q = f(K, L)\)
  • \(MP_K = \partial f/\partial K\)
  • \(MP_L = \partial f/\partial L\)
  • Diminishing MP: \(\partial^2 f/\partial L^2 < 0\)
  • Equal-output input bundles
  • Like ICs but for production
  • Convex shape (substitutable inputs)
  • Higher isoquant = more output
  • \(\text{MRTS}_{LK} = MP_L / MP_K\)
  • Slope of isoquant
  • Via implicit diff of \(f = \) const
  • Cobb-Douglas: \((\beta/\alpha)(K/L)\)
  • Test \(f(\alpha K, \alpha L)\)
  • CRS: exponents sum to 1
  • IRS: \(> 1\)
  • DRS: \(< 1\)
  • Cobb-Douglas: \(AK^\alpha L^\beta\)
  • Leontief: \(\min(K/a, L/b)\)
  • Perfect subs: \(aK + bL\)
  • SR: one input fixed
  • LR: all variable
Key takeaway: \(\text{MRTS} = MP_L/MP_K\) is the slope of an isoquant — the producer analog of MRS. For Cobb-Douglas \(Q = AK^\alpha L^\beta\): \(\text{MRTS} = \dfrac{\beta}{\alpha} \cdot \dfrac{K}{L}\). Returns to scale = sum of exponents.

Costs of Production
8.1Cost-Min Setup
8.2Lagrangian + \(\mu\)
8.3Cost Function
8.4SR Cost Curves
8.5LR vs SR Costs
  • Minimize \(wL + rK\)
  • Subject to \(f(K, L) = q\)
  • Dual to utility max
  • Isocost: \(wL + rK = c\) (line)
  • \(\mathcal{L} = wL + rK + \mu(q - f)\)
  • Tangency: \(\text{MRTS} = w/r\)
  • FOCs solve for \(L^*, K^*\)
  • Equimarginal: \(MP_L/w = MP_K/r\)
  • \(c(w, r, q)\) = min cost for \(q\)
  • Conditional demands \(L^*, K^*\)
  • Cobb-Douglas CRS: linear in \(q\)
  • \(MC = dc/dq\)
  • \(K\) fixed, \(L\) variable
  • \(ATC = TC/q\), \(AVC, AFC\)
  • \(MC = dTC/dq\)
  • MC crosses ATC, AVC at their min
  • All inputs variable in LR
  • LR ATC \(\leq\) any SR ATC at the same \(q\)
  • Firm picks the best \(K\) in LR
  • U-shape if not CRS
Key takeaway: Cost-min is the producer’s Lagrangian: \(\mathcal{L} = wL + rK + \mu(q - f(K, L))\). Tangency: \(\text{MRTS} = w/r\). Solve the FOCs for \(L^*(w, r, q)\) and \(K^*(w, r, q)\) — the conditional input demands.

Top 12 Mistakes to Avoid

1

MRS \(\ne\) MU. Always the ratio: \(\text{MRS} = MU_1/MU_2\). Don’t write \(MU_1\) and call it MRS.

2

Midpoint elasticity is 1116. In 2316 use the derivative: \(\varepsilon = (dQ/dP)(P/Q)\). Different formula, same concept.

3

Wrong Lagrangian sign. \(\mathcal{L} = U + \lambda(I - p_1 x_1 - p_2 x_2)\) — minus inside, plus on \(\lambda\). Be consistent across all FOCs.

4

Tangency fails for perfect substitutes. MRS is constant, so \(\text{MRS} = p_1/p_2\) either holds everywhere or nowhere. Use \(MU/p\) comparison — spend all on the higher one.

5

Sign of the IE term in Slutsky. The Slutsky term is \(-x \cdot \partial x/\partial I\). For a normal good (\(\partial x/\partial I > 0\)), this is negative — IE reinforces SE.

6

SE is always non-positive. Hicksian (compensated) demand slopes down for own price — no exceptions. Giffen arises from the IE flipping, not the SE.

7

Cobb-Douglas own-price elasticity = \(-1\). Because \(x_i^* = \alpha_i I / p_i\). Income elasticity = \(+1\). These are useful to memorize.

8

Isoquants \(\ne\) indifference curves. Isoquants live in \((K, L)\) space; the slope is \(-\text{MRTS}\), not \(-\text{MRS}\).

9

Returns to scale \(\ne\) diminishing MP. Test RTS by computing \(f(\alpha K, \alpha L)\), NOT by signing the second derivative.

10

\(\lambda\) vs \(\mu\) have different units. \(\lambda\) in utility-max is utils per dollar. \(\mu\) in cost-min is dollars per unit of output — that’s why \(\mu = MC\).

11

MC = ATC only at the minimum. Otherwise MC \(\ne\) ATC. MC is the derivative of TC; ATC is the average.

12

LR ATC is the lower envelope of SR ATCs. Not the average, not the sum. At each \(q\), one specific \(K\) is optimal, and the SR ATC for that \(K\) is tangent to LR ATC at that \(q\).

Day-of-Test Game Plan

1. Scan your formula sheet first.

30 seconds to remind yourself what you have written down — so you don’t re-derive things you brought.

2. Identify the problem type before solving.

Lagrangian? Slutsky? Cost-min? Comparative statics? Naming the technique is half the work — the algebra follows.

3. Write the FOCs cleanly.

For Lagrangians, write all three FOCs in a row, then divide the first two to eliminate \(\lambda\). Partial credit lives in clean FOCs even when arithmetic goes wrong.

4. Cobb-Douglas shortcut: use it.

If you see \(U = x_1^\alpha x_2^{1-\alpha}\) or \(f = K^\alpha L^\beta\), jump straight to \(x_i^* = \alpha_i I/p_i\) or use the MRTS shortcut. No need to redo the Lagrangian every time.

5. Check units & signs.

SE \(\leq 0\). \(\lambda > 0\) for binding constraints. Elasticities of demand are negative. MRS positive. Easy points lost on missed signs.

Mindset

2316 rewards structural reasoning: write the Lagrangian, take the FOCs, interpret \(\lambda\) (utility max) or \(\mu\) (cost min), and read off the demand or cost function. The mechanics are mechanical once the structure is right.
